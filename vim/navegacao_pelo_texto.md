# Navegação pelo texto no Vim

## Entrando no modo de Inserção

a -> igual i, mas coloca o cursos após a letra selecionada

A -> insere no fim da linha

I -> insere no começo da linha

o,O -> insere uma linha abaixo ou acima.

## Navegação no modo Normal

w,b -> avança ou retorna uma palavra. "word" "back"

W -> qualquer sequencia de caracteres entre dois espaços.

e -> vai para o fim da palavra; "end"

0,$ -> navega para o começo ou final da linha

^ -> navega para o primeiro char da linha

f -> procura o próximo char digitado na linha e move para a primeira ocorrencia use ; ou , para avançar ou voltar. "find"

F -> procura antes do cursor.

G -> Navega para o começo da última linha

gg -> navega para o começo da primeira linha

zz -> muda a visualização da tela de modo que o cursos fique no centr vertical

M -> navega para o meio do arquivo

## Entre parenteses

% -> navega entre (), {}, etc
